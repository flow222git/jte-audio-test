# 京房八宮起卦

靜態網頁工具，可直接開啟 `index.html` 使用。

功能包含：

- 三枚銅錢隨機起卦
- 手動輸入六爻數值 6、7、8、9
- 本卦、變卦、八宮歸屬、世應、游魂/歸魂
- 納甲地支、五行、六親爻表
- 飛伏視圖：本宮伏神、對宮伏象、用神缺位提示
- 進階時空：月建、日辰、時辰、六神、空亡、月破日破、旺衰提示，進入頁面自動帶入本機時間，也可重新帶入
- 依卦象、八宮、世應、動爻、飛伏、時空與問事類型產生規則化判斷
- 白話總結：分成重點判斷、不同向度解釋、最後歸納與方向作法建議
- 問法模板：依問事類型提供可直接套用的問題
- 系統判斷：依問題文字自動推測問事類型，也可用下方按鈕切換，並高亮套用的五向度組合
- 問題對焦：依問句判斷可否推進、卡點風險、下一步作法、走勢發展或選擇取捨，讓解讀直接回應問題
- 圖文摘要：先顯示一眼看判斷、可借力與需留意向度，詳細內容可再展開
- 起卦回饋：三錢起卦會由初爻到上爻逐一生成，完成後顯示卦已成提示；手動六爻則快速套用

## 模型

工具依幾層模型整理：

- 八宮：以八純卦為宗主，乾、震、坎、艮為四陽宮，坤、巽、離、兌為四陰宮。
- 納甲：每一爻裝入天干地支，使卦象帶有時間、方位與五行屬性。
- 六親：以本宮五行為我，定父母、子孫、妻財、官鬼、兄弟。
- 飛伏：卦面可見者為飛爻；用神不現時，以本宮純卦同位爻尋伏神，並以對宮伏象參照陰陽背面。
- 時空：進入頁面會自動帶入本機日期時間，也可手動輸入月建、日辰與時辰，或按「重新帶入本機時間」更新；工具會加入六神、旬空、沖合與旺衰判讀。日辰由本機公曆日期換算，不需要連網；若採子初換日，23:00 後可手動調到隔日。月建自動值以常用節氣日近似，節氣交界請手動校正。
- 判斷：依問事類型切換權重，例如財務優先看妻財、子孫、兄弟，健康優先看官鬼、子孫、父母，再合世應、動爻、飛伏與時空強弱。

這是傳統規則的研究與輔助判讀工具，不替代醫療、法律、投資或其他專業建議。
