# 京房八宮起卦

靜態網頁工具，可直接開啟 `index.html` 使用。

功能包含：

- 三枚銅錢隨機起卦
- 手動輸入六爻數值 6、7、8、9
- 本卦、變卦、八宮歸屬、世應、游魂/歸魂
- 納甲地支、五行、六親爻表
- 飛伏視圖：本宮伏神、對宮伏象、用神缺位提示
- 依卦象、八宮、世應、動爻與問事類型產生規則化解讀

## 模型

工具依四層模型整理：

- 八宮：以八純卦為宗主，乾、震、坎、艮為四陽宮，坤、巽、離、兌為四陰宮。
- 納甲：每一爻裝入天干地支，使卦象帶有時間、方位與五行屬性。
- 六親：以本宮五行為我，定父母、子孫、妻財、官鬼、兄弟。
- 飛伏：卦面可見者為飛爻；用神不現時，以本宮純卦同位爻尋伏神，並以對宮伏象參照陰陽背面。
